## RoyaleStats

RoyaleStats — это веб-платформа для игроков мобильной игры Clash Royale,
объединяющая четыре ключевых инструмента:
энциклопедию карт, конструктор колод, калькулятор прокачки и мета-аналитику сезона.

## Цель и задачи системы

__Цель:__ Создать удобный универсальный веб-инструмент, объединяющий
все базовые знания и инструменты Clash Royale в одном месте.

__Задачи системы:__

1) Реализовать энциклопедию карт с фильтрацией по типу, редкости и арене.

2) Реализовать конструктор колод с подсчётом среднего элексира и анализом баланса.

3) Реализовать калькулятор прокачки, показывающий сколько карт,
золота и алмазов нужно до максимального уровня.

4) Реализовать мета-аналитику текущего сезона — популярные карты
и колоды с визуализацией в виде графиков и диаграмм.

5) Реализовать SQL базу данных с таблицами карт (clash_cards)
и уровней короля (king_levels).

## Целевая аудитория

* Активные игроки Clash Royale, которым нужны удобные инструменты
для прогресса в игре.

* Начинающие игроки, желающие разобраться в картах, колодах
и механиках прокачки.

* Опытные игроки, отслеживающие мету и оптимизирующие свои колоды
под текущий сезон.

## Содержание сайта

1. Страница 1. «Энциклопедия карт» — каталог всех карт с фильтрацией
и подробными характеристиками каждой карты.
2. Страница 2. «Конструктор колод» — сборка колоды из 8 карт
с анализом баланса и среднего элексира.
3. Страница 3. «Калькулятор прокачки» — расчёт необходимых ресурсов
для прокачки карт до максимального уровня.
4. Страница 4. «Мета-аналитика» — визуализация популярных карт
и колод текущего сезона в виде графиков и диаграмм.

## Функциональные возможности

* Просмотр и фильтрация карт по типу, редкости и арене открытия.

* Сборка колоды из 8 карт с автоматическим подсчётом среднего элексира
и отображением баланса типов карт.

* Расчёт количества карт, золота и алмазов, необходимых для прокачки
карты до максимального уровня.

* Визуализация мета-статистики текущего сезона в виде графиков и диаграмм.

* Хранение данных в SQL базе данных с таблицами clash_cards и king_levels.
