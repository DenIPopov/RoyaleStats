## ❤️ RoyaleStats

RoyaleStats — это веб-платформа для игроков мобильной игры Clash Royale,
объединяющая четыре ключевых инструмента:
* подбор колод для каждой арены
* калькулятор прокачки карт
* базы данных об уровне короля и теккущего прогресса игрока
* лента новостей - Clash News

RoyaleStats также предоставляет актуальные новости об обновлениях игры, помогает игрокам на любых 
аренах подобрать эффективную колоду и даёт возможность через личный ID отслеживать прогресс прокачки. 

Это единый центр управления игровым развитием — от новичка до топ-игрока.

## 🔥 Цель и задачи системы

__Цель:__ Создать удобный универсальный веб-инструмент, объединяющий
все базовые знания и инструменты Clash Royale в одном месте.

__Задачи системы:__

* Реализовать главную страницы веб-сайта, где будут содержаться все инструменты для разваития игркока

* Подбор колод для каждой арены (мета сезона)

* Реализовать калькулятор прокачки карт

* Создать базу данных с пользовательским ID игрока

* Осуществить страницу нововведений Clash News

## 🫶 Целевая аудитория

* Активные игроки Clash Royale, которым нужны удобные инструменты
для прогресса в игре.

* Начинающие игроки, желающие разобраться в картах, колодах
и механиках прокачки.

* Опытные игроки, отслеживающие мету и оптимизирующие свои колоды
под текущий сезон.

* Аналитики и авторы контента (стримеры, блогеры), которым нужны данные о мете для создания видео и гайдов.

* Киберспортсмены, которые следят за актуальными колодами и готовятся к турнирам.

## 💎 Содержание сайта

* Страница 1: «Главная страница» — навигация по всем разделам сайта, краткое описание возможностей RoyaleStats, баннер с последними новостями.
* Страница 2. «Подбор колод по аренам» — выбор арены (1–22), отображение популярных колод и карт для выбранной арены с визуализацией в виде графиков и диаграмм (мета-аналитика сезона).
* Страница 3. «Калькулятор прокачки» — расчёт необходимого количества карт, золота и алмазов для прокачки выбранной карты до максимального уровня.
* Страница 4. «База данных и поиск игрока» — поиск игрока по личному ID, отображение его карт, уровня короля и прогресса прокачки на основе данных из SQL базы данных (таблицы clash_cards и king_levels).
* Страница 5. «Clash News» — новостная лента с актуальными новостями об обновлениях игры, новых картах, балансных изменениях и событиях Clash Royale.

## 💡 Функциональные возможности

* Просмотр и фильтрация карт по типу, редкости и арене открытия.

* Сборка колоды из 8 карт с автоматическим подсчётом среднего элексира
и отображением баланса типов карт.

* Расчёт количества карт, золота и алмазов, необходимых для прокачки
карты до максимального уровня.

* Визуализация мета-статистики текущего сезона в виде графиков и диаграмм.

* Хранение данных в SQL базе данных с таблицами clash_cards и king_levels.
