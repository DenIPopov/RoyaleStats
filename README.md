# RoyaleStats

## RoyaleStats - веб-платформа для игроков мобильной игры Clash Royale

### RoyaleStats — это веб-платформа для игроков Clash Royale, объединяющая четыре ключевых инструмента:
1) Энциклопедия карт с фильтрацией по типу, редкости и арене.
2) Конструктор колод с подсчётом среднего элексира и анализом баланса.
3) Калькулятор прокачки, показывающий сколько карт, золота и алмазов нужно до максимального уровня.
4) Мета-аналитика текущего сезона — популярные карты и колоды с визуализацией в виде графиков и диаграмм.
Мы создадим удобный универсальный и единый инструмент, объединяющий все базовые знания Clash Royale в одном месте. Целевой аудиторией будут активные игроки в Clash Royale, которым нужны удобные и эффективные инструменты для прогресса в игре.

 У нас будет реализована активная БД, состоящая из таблиц. Их может быть несколько. Примеры. Таблица 1 - карты Clash Royale (clash_cards). Они имеют такие параметры как тип, редкость, название карты и т.д. Таблица 2 - уровень короля (king_level\s). Параметры: количество золота\карт, уровень карт и т.д. ## Тематика сайта, название

Веб-сервис для продуктивности и тайм-менеджмента (инструмент типа To-Do / Task Manager).

__Название проекта: TaskFlow__ (или DoNow, EasyTrack).

__Суть__: Платформа для постановки, отслеживания и выполнения личных или командных задач.

## Цель и задачи системы

__Цель__: Разработать удобный веб-интерфейс для управления задачами, который поможет пользователям структурировать дела, соблюдать дедлайны и повышать личную эффективность.

__Задачи системы:__

1) Обеспечить создание, редактирование и удаление задач (CRUD).

2) Реализовать систему категорий и приоритетов.

3) Научить систему фильтровать задачи по статусу (активные/завершенные).

4) Добавить поиск и сортировку.

5) Организовать хранение данных пользователя.
