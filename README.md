# RoyaleStats

## RoyaleStats - веб-платформа для игроков мобильной игры Clash Royale

### RoyaleStats — это веб-платформа для игроков Clash Royale, объединяющая четыре ключевых инструмента:
1) Энциклопедия карт с фильтрацией по типу, редкости и арене.
2) Конструктор колод с подсчётом среднего элексира и анализом баланса.
3) Калькулятор прокачки, показывающий сколько карт, золота и алмазов нужно до максимального уровня.
4) Мета-аналитика текущего сезона — популярные карты и колоды с визуализацией в виде графиков и диаграмм.
Мы создадим удобный универсальный и единый инструмент, объединяющий все базовые знания Clash Royale в одном месте. Целевой аудиторией будут активные игроки в Clash Royale, которым нужны удобные и эффективные инструменты для прогресса в игре.

 У нас будет реализована активная БД, состоящая из таблиц. Их может быть несколько. Примеры. Таблица 1 - карты Clash Royale (clash_cards). Они имеют такие параметры как тип, редкость, название карты и т.д. Таблица 2 - уровень короля (king_level\s). Параметры: количество золота\карт, уровень карт и т.д.
